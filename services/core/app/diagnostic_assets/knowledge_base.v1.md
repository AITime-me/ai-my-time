# Diagnostic methodology knowledge base — v1

Use this as a small editable methodology layer, not as customer facts.

1. Reconstruct one path: first contact → owner → next action → handoff → result.
2. Find the smallest visible manual gap: an unassigned request, a missing next step, a lost handoff or unclear status.
3. Offer one low-risk action the team can try without redesigning its systems.
4. Separate stable workflow mechanics (automation), work with free text or context (AI), and judgement/exception handling (human).
5. Identify only the clarifications genuinely needed for a later expert consultation.
